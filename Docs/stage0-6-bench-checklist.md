# 阶段0～6台架验收清单

> 当前状态：全部`PENDING-HW`。本清单未包含真实12V电磁锁；PA8只接LED和限流电阻。

## 1. 首次上电前安全检查

1. 不连接LYO3C电磁锁、继电器或MOSFET功率板。
2. 用万用表确认开发板3.3V和5V电源轨，无短路后再接模块。
3. DS3231若安装CR2032，先确认D2/R4充电支路是否导通；未确认前只用3.3V给RTC板供电，禁止5V。
4. AS608先不接PA3。模块以3.3V供电后，测量其TXD高电平；只有确认不超过3.3V并核对连接器线序后，才将TXD接PA3、RXD接PA2。
5. 蜂鸣器型号和高/低有效未确认时保持PB1悬空；不要直接驱动大功率蜂鸣器。
6. PA8接`330Ω～1kΩ`限流电阻和LED作为模拟锁；不要连接12V负载。

## 2. 烧录与基础功能（阶段1）

1. 用ST-Link连接SWDIO/PA13、SWCLK/PA14、GND和3.3V参考电平。
2. 烧录`Firmware/SmartDoorLock/MDK-ARM/SmartDoorLock/SmartDoorLock.hex`。
3. USART1使用115200、8N1记录完整上电日志。
4. 确认PC13板载LED约500ms翻转、OLED显示待机界面，PA8上电保持低。

返回证据：接线全景、PA8上电电压、OLED照片、从上电开始的完整串口日志。

## 3. 密码与自动上锁（阶段2）

1. 待机按`A`，输入默认普通密码`123456#`。
2. 确认PA8 LED点亮约5秒后自动熄灭，期间键盘、OLED和心跳仍响应。
3. 输入错误密码、少于4位密码并确认、输入中等待30秒，确认均不会点亮PA8。
4. 检查4×4每个按键仅产生一次事件；若键位错乱，记录键帽和排线实际对应关系。

返回证据：正确/错误/超时三段日志，5秒动作视频或带时间标记的照片，键位映射表。

## 4. RTC与EEPROM（阶段3）

1. 确认OLED时间连续变化；断开RTC主电源后等待至少2分钟，再恢复供电检查时间是否连续。
2. 按`D`输入默认管理员密码`000000#`，选`1`修改普通密码，断电重启后验证新密码仍有效。
3. 重复断电恢复至少3次用于本轮开发验证；论文要求的20次测试需以后单独完整执行并逐次记录。
4. 拔掉AT24C02后启动，确认日志报告降级且默认密码仍可工作，但管理写操作失败。

返回证据：RTC断电前后照片/时间记录、3次重启日志、EEPROM缺失日志。

## 5. RFID（阶段4）

1. 管理员菜单选`2`，刷卡添加；退出后刷该卡，确认PA8 LED开锁。
2. 菜单选`3`删除同一张卡；退出后再刷，确认拒绝。
3. 重复添加、删除不存在卡，并尝试加入第9张卡，记录OLED提示和日志。
4. 拔掉RC522后重启，确认密码路径仍可用且主循环没有卡死。

返回证据：RC522接线近照、版本/启动日志、添加/开锁/删除/拒绝日志。

## 6. 指纹（阶段5）

1. 完成TXD电平和线序确认后再连接AS608，观察启动日志中的口令验证结果。
2. 管理员菜单选`4`，输入模板ID `0～299`，按提示采集同一手指两次。
3. 退出后验证授权指纹能开锁；未录入指纹被拒绝。
4. 菜单选`5`删除模板ID，再验证该手指不能开锁。
5. 运行时拔掉AS608，确认约2秒后超时并继续响应键盘、RFID和自动上锁。

返回证据：AS608正反面与线序照片、TXD高电平测量值、录入/搜索/删除/断开日志。

## 7. 管理员与安全策略（阶段6）

1. 按`D`验证普通密码不能进入管理员菜单，管理员密码可以进入。
2. 在管理员菜单分别修改普通PIN和管理员PIN，断电后验证两者恢复。
3. 混合使用错误密码、未授权卡和未授权指纹累计5次，确认进入60秒临时锁定。
4. 锁定期间尝试三种认证，确认PA8始终保持低；60秒后确认自动恢复。
5. 观察系统连续运行至少10分钟；确认OLED、心跳、键盘和各认证任务没有因IWDG反复复位。
6. 若安装低电流有源蜂鸣器，先串联限流并确认PB1高有效假设；否则保持不接并记录`PENDING-HW`。

返回证据：管理员菜单照片、失败1～5次和锁定解除的连续日志、PA8锁定期电压、10分钟运行视频或时间连续照片、是否发生复位。

## 8. 结果判定

- 每项只有在日志、照片或测量值满足标准后才能从`PENDING-HW`改为`BENCH-PASS`。
- 发现复位、OLED闪屏、RFID掉线、指纹超时异常或PA8误动作时立即停止，保留完整日志并描述接线和供电条件。
- 阶段0～6通过后仍不得接真实电磁锁；阶段7必须另行完成驱动空载、电平、续流、电源容量、共地和100次稳定性测试。
